# Gullak chunky UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the whole website and Android app in the approved "chunky & loud" look, rename the product to Gullak with a new logo, favicon and app icon, and add the streak, the spending breakdown and the asset split.

**Architecture:** On the backend, there's one new tiny endpoint (`/api/streak`) and two new fields on existing responses (`expense_by_category` on the transactions list, `asset_split` on the dashboard), with no migration. The web gets global tokens (with the Tailwind `zinc` scale remapped to warm ink, and the `dark:` variant disabled), then a small chunky component kit, then a screen-by-screen pass. Mobile gets a light-only Paper theme with Nunito, a matching component kit, then a screen-by-screen pass. Each platform keeps its own layout (sidebar and tables on the web, floating tab bar and stacks on the phone).

**Tech Stack:** FastAPI + SQLAlchemy + pytest; Next 16 / React 19 / Tailwind 4; Expo 58 / react-native-paper 5 / expo-router; `sharp` + Pillow for icon rendering.

**Spec:** `docs/superpowers/specs/2026-11-11-chunky-ui-design.md` (read it, including "Calls made by Claude" and "Brand"). Visual references: `.superpowers/brainstorm/4979-1794386878/content/all-screens.html` (app), `web-screens-v2.html` (web), `name-logo.html` option 1 (logo). They're git-ignored and local only, so open them in a browser.

## Global Constraints

- Palette: bg `#FFFDF5`, ink `#1A1A1A`, card `#FFFFFF`, green `#58CC02`, yellow `#FFC800`, pink `#FF4B8B`, blue `#1CB0F6`, purple `#A560FF`, orange `#FF7A00`, due highlight `#FFF1C2`. Gain/loss text: `#2E8B00` / `#D7263D`.
- **Contrast**: any text on a coloured tile must reach ≥4.5:1. Use deeper "-strong" shades for tiles that carry white text (pick values ≥4.5:1 against `#FFFFFF`, e.g. green ≈ `#2B7A0B`, blue ≈ `#0B6FA4`, pink ≈ `#C2185B`, purple ≈ `#7B3FD1`, orange ≈ `#B85000`, verified with a contrast checker). Yellow tiles always use ink text. Functional text is ≥11px.
- Borders 2.5px ink; card radius 18px; input radius 14px; hard shadow `0 4px 0 ink` (rows/chips `0 3px 0`); pressed state: translateY(4px), no shadow; motion off under reduced motion.
- Font: Nunito 700/800/900; amounts use tabular numbers.
- Light only on both platforms.
- Display name "Gullak"; Android package, slug and scheme unchanged.
- Never remove existing accessibility attributes (`aria-*`, `role`, labels); restyle focus rings, don't drop them.
- Every existing test keeps passing: `cd backend && uv run pytest`, `cd frontend && npm test && npm run lint && npm run build`, `cd mobile && npm test && npm run typecheck && npm run lint`.
- No Alembic migration may be added on this branch.

## Review Focus

1. **Long names and big amounts** (₹1,23,45,67,890.00, a 60-char goal name) in tiles, rows and table cells must wrap or ellipsize, never overflow the chunky border. Tasks 6 and 16 add a long-content story to the visual checks.
2. **Empty states**: a new user with no accounts, transactions, goals or holdings sees friendly empty tiles, not "₹0" bars or a NaN ring. Each screen task checks the empty account.
3. **Breakdown with odd data**: an uncategorised expense, more than 4 categories, a month with only EMI interest, a month with nothing spent. This is covered by Task 3's tests, and the UI hides the bar when the list is empty.
4. **Streak edges**: a transaction logged at 23:30 IST counts for that India date. A gap yesterday resets the streak. Logging nothing today but something yesterday keeps the streak. This is covered by Task 2's tests.
5. **Negative net worth / losses**: a pink or loss styling path for negative totals and negative unrealised gains, with no "+-5%" sticker. This is covered by Task 5's sticker tests and checked in Tasks 8 and 20.
