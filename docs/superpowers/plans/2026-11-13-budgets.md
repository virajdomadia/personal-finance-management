# Budgets, Next 30 Days and Safe to Spend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Monthly budgets per expense category, one list of everything due in the next 30 days with a running balance, and a "safe to spend" figure with its breakdown. Backend, website and Android app.

**Architecture:**
- **Table:** `budgets` (one row per change, `effective_from` month, NULL amount = removed).
- **Logic:** `backend/app/api/budgets.py` (versions, lines from `cash_flow.grouped`, totals) and `backend/app/api/upcoming.py` (due items from the existing due rules, running balance, safe to spend).
- **Routes:** `routes/budgets.py` (`/budgets`), `routes/upcoming.py` (`/upcoming`, `/safe-to-spend`).
- **Reuse:** `app.api.cash_flow` for spent; `app.api.recurring.status` gains a look-ahead; `dashboard.card_bill` becomes `card_bills`; `sips.load_due`, `deposits.rd_due_months`, `goals.reminder_due`, `loans.next_emi`.
- **Migration:** `2026_11_13_1500-<rev>_add_budgets.py`, after `2d46fef3dab4`.

**Spec:** [docs/superpowers/specs/2026-11-13-budgets-design.md](../specs/2026-11-13-budgets-design.md).

## Global Constraints

- Money is `Decimal`, crosses the API as 2-decimal strings; sums in Python. Clients do no money arithmetic: percents and bars come from the server.
- Every query is scoped to `user.id`. Validation errors are 422 via `field_error`; other users' ids 404.
- The schema must match the models exactly (`alembic check` in `test_pg_migrations.py`).
- Tests freeze "today" by patching `today_india` in the route modules.
- Web and Android each get their own UI. No chart library, no new native modules.

## Review Focus

1. A budget's spent equals the `/cash-flow` figure for the same category and month (rollup included).
2. Changing this month's budget leaves last month's figures unchanged.
3. Safe to spend: no salary reminder, overspent budgets, negative balances, card dues, and a rent reminder plus a rent budget counted once.
4. The running balance ignores goal set-asides, card charges and transfers within bank/cash/wallet.
